# حزمة البرومبتات المستقلة لـ ARGON Clouds — 4 نوفمبر 2026

هذه الحزمة تحتوي على سبعة برومبتات منفصلة. افتح محادثة مستقلة لكل Cloud، وأرسل له **ملف البرومبت الخاص به فقط** مع المرفقات المطلوبة في مقدمته. لا ترسل برومبت C1 إلى C7 أو العكس، ولا تجعل أكثر من Cloud يحرر نفس الملفات.

## الملفات

- `C1_ORCHESTRATOR_PROMPT.md` — المنسّق والمعماري المسؤول عن تجميع مخرجات C2–C6 وإعداد حزمة مراجعة C7.
- `C2_SECURITY_TRUST_AUTHZ_PROMPT.md` — الأمن والثقة والهوية والصلاحيات وتجربة RP-13.
- `C3_CONTEXT_EVIDENCE_PROMPT.md` — عزل السياق والمعرفة وحداثة الأدلة والتسليم والاستئناف.
- `C4_EXECUTION_MUTATION_BOUNDARIES_PROMPT.md` — حدود التنفيذ والتغييرات وأسطح الهجوم واستعادة Wave 3.5.
- `C5_OPERATOR_APPROVAL_PROMPT.md` — تحكم المشغّل البشري والموافقة والقبول وسجل المصدر.
- `C6_EVALUATION_VERIFICATION_PROMPT.md` — القياس والتقييم والتحقق؛ يحافظ على قبول C6 بوصفه DESIGN-ONLY ولا يعيد تأليف أعماله.
- `C7_INDEPENDENT_AUDITOR_PROMPT.md` — التدقيق المستقل؛ يبدأ بفرز الخصوصية ولا يصدر حكمًا نظيفًا دون حزمة مجمدة وأدلة قابلة للتحقق.

## طريقة الإرسال

1. أنشئ جلسة/مساحة مستقلة لكل Cloud.
2. أرسل البرومبت المطابق له، ثم المرفقات التي يطلبها قسم `Run this prompt...` في بداية الملف.
3. اطلب منه تنفيذ المهمة ضمن حدودها وتسليم الملفات المحددة مع `SHA256SUMS.txt`.
4. لا تخلط نتائج Cloud مع آخر قبل اكتمال التسليم والتحقق من الملفات والبصمات.
5. C7 يبدأ Phase A (Privacy Triage) من الآن. أما Phase B فينتظر حزمة C1 النهائية المجمدة ومخرجات C2–C6.
6. C1 يحافظ على مسودة الدمج ولا يصدر حكم تدقيق. C6 لا يعيد كتابة الحزم المقبولة تصميميًا. لا يوجد في هذه البرومبتات إذن بالتنفيذ أو Wave 4 أو الكتابة إلى ARGON-HEALTH.

## الذاكرة / القاموس

كل برومبت يطلب من الـCloud حفظ بطاقة هويته الثابتة باسم فريد (`ARGON_CLOUD_IDENTITY_C1` إلى `..._C7`) في ذاكرته الدائمة إن كانت الميزة متاحة. إذا لم تكن الذاكرة الدائمة متاحة، يجب أن يصرّح بذلك ويحتفظ بالبطاقة ضمن سياق الجلسة ويكررها عند تسليم أي متابعة. لا يجوز له ادعاء حفظ دائم لم يحدث.

## قاعدة مشتركة حاسمة

هذه مهام استرجاع وتدقيق وتصميم وتنسيق **للقراءة فقط**. لا تعديل للمستودعات، لا commits أو PRs أو push أو deploy، لا تشغيل Runtime أو mutation tests، لا Wave 4، ولا أي machine writes إلى ARGON-HEALTH، ولا لمس لـ Legacy ARGON. أي صلاحية أوسع تتطلب تفويضًا منفصلًا وصريحًا بعد إغلاق بوابات الحوكمة والأمن.
